## Problem: Two Sum (Easy)

**Link:** https://leetcode.com/problems/two-sum/

### Approach

We need to find two numbers in the array whose sum is equal to the given target. We check each pair of elements and return their indices when their sum matches the target.

### Complexity

* **Time:** O(n²)
* **Space:** O(1)

### Notes

The array can contain duplicate values, and the same element cannot be used twice. The solution returns the indices of the two numbers whose sum equals the target.
